## Overview
This project focuses on detecting and classifying fruits as **fresh or rotten** using the **YOLOv5 deep learning algorithm**.  
The system uses **Python**, **OpenCV**, and **PyTorch**, achieving **over 90% accuracy** on test datasets.

## Objectives
- Build a real-time detection system for fruit classification  
- Train YOLOv5 on a custom fruit dataset  
- Separate fresh and rotten fruits automatically  

## Technologies Used
- YOLOv5  
- Python  
- OpenCV  
- PyTorch
