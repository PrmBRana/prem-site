STM32 Dual-Core IPCC Engineering

STM32H747 / WB55 Zero-Copy Mailbox Cache Coherency Hardware Semaphores

Designed robust asymmetric multiprocessing (AMP) firmware architectures separating critical real-time attitude control (Cortex-M7) from communication protocol stacks and file system operations (Cortex-M4).

  • Zero-Copy Mailbox Architecture: Uses bidirectional IPCC hardware channels to exchange 32-bit pointers referencing shared SRAM3 without memory copying penalties.
  • Hardware Cache Coherency: Implemented precise cache maintenance using SCB_CleanDCache_by_Addr() prior to transmission and SCB_InvalidateDCache_by_Addr() on the receiving core.
  • Atomic Resource Protection: Hardware Semaphores (HSEM) prevent concurrent access to shared SPI busses, NOR Flash, and transceiver radios.

Lock-Free Circular FIFO Architecture

Single-Producer Single-Consumer Power-of-2 Indexing __DMB() Memory Barrier

Engineered high-frequency, non-blocking ring buffers to pipe UART/SPI telemetry and DMA ADC samples between hardware ISR routines and FreeRTOS processing tasks without disabling interrupts or risking race conditions.

  • Zero Modulo Overhead: Uses powers-of-two capacity (SIZE = 2^N) so indices wrap effortlessly via bitwise AND: head & (SIZE - 1), saving precious CPU cycles on microcontrollers without hardware division.
  • Memory Barriers: Inlined ARM CMSIS __DMB() data memory barriers ensure data bytes are flushed into RAM before advancing volatile pointer indices.
  • Interrupt Safety: Safe for single-producer single-consumer execution without disabling interrupts (__disable_irq()), preserving deterministic low latency.
ring_buffer.c Lock-Free C Implementation 
bool RingBuf_Push(RingBuf_t *rb, uint8_t byte) {
  uint32_t head = rb->head;
  uint32_t tail = rb->tail;
  if ((head - tail) >= RING_BUFFER_SIZE) return false; /* Overflow */
  
  rb->buffer[head & (RING_BUFFER_SIZE - 1)] = byte;
  __DMB(); /* Data Memory Barrier ensures write commits before index update */
  rb->head = head + 1;
  return true;
}

Space Telemetry & RF Modulation

GMSK BT=0.5 AX.25 HDLC UI Frame G3RUH Scrambler CW Morse Beacon

Designed digital RF modem processing chains for CubeSat transceivers (AX5043, CC1120, SX1268). Engineered packet framing conforming to international amateur satellite standards.

  • GMSK / GFSK Pulse Shaping: Implemented Gaussian pre-modulation filters with bandwidth-time product $BT = 0.5$ and $BT = 0.3$ to eliminate sideband splatter and maintain constant RF envelope.
  • AX.25 UI Frame Protocol: Assembled Layer-2 HDLC telemetry frames with opening/closing flags (0x7E), zero-bit insertion (bit stuffing after 5 consecutive 1s), and 16-bit CRC-CCITT polynomials.
  • G3RUH 9600/19200 Scrambler: Applied polynomial $1 + x^{12} + x^{17}$ LFSR whitening scrambler to ensure continuous bit transitions, DC balance, and rapid clock recovery in ground station decoders (SatNOGS).
  • Automated CW Beacon: C-based Morse code state machine transmitting satellite callsign, battery status, and temperatures for global amateur radio operators.

Fail-Safe LittleFS for CubeSat OBC

Power-Loss Resilient Dynamic Wear Leveling Bounded RAM footprint

Integrated LittleFS on external NOR Flash (W25Q64/W25Q128) for mission flight logging, attitude calibration tables, and camera image chunk storage.

  • Copy-on-Write Metadata Pairs: Prevents corruption even if power is abruptly severed during solar eclipse or battery low-voltage cutoff.
  • Dynamic Wear Leveling: Balances erase cycles across blocks to maximize flash lifetime in harsh space environments.
  • Bounded Memory: Operates reliably with tiny RAM lookahead buffers, vital for memory-constrained flight computers.

ASIC Implementation Workflow

1. RTL Specification & Simulation

Authored synthesizable Verilog for the decode, ALU, control logic, register files, and data hazard forwarding units. Verified cycle accuracy with Verilator and Python-based Cocotb testbenches.

2. Logic Synthesis & Static Timing Analysis

Synthesized RTL into SkyWater 130nm standard cell gate-level netlists using Yosys. Conducted Static Timing Analysis (STA) via OpenSTA to ensure zero setup and hold timing violations.

3. Floorplanning, Placement & CTS

Configured die boundaries, IO pad assignments, and power distribution grids (VDD/VSS rings). Executed Clock Tree Synthesis (CTS) for low-skew clock distribution.

4. Routing, DRC/LVS & GDSII Tapeout

Detailed metal layer routing (M1–M5), antenna diode insertion, and rigorous Design Rule Checking (DRC) and Layout Versus Schematic (LVS) verification via Magic and Klayout.
