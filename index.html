VLSI Design // Open-Source Silicon

RISC-V 5-Stage Pipelined Processor Core

Designed and simulated a custom 32-bit RISC-V CPU architecture adhering to the RV32I user-level ISA using synthesizable Verilog HDL. Built both single-cycle and 5-stage pipelined processor models with hazard forwarding units, branch prediction, and stall logic. Integrated UART, SPI, and GPIO peripherals. Verified with ModelSim, Verilator, and Python-based cocotb testbenches, targeted for the SkyWater 130nm ASIC flow via Tiny Tapeout.

STM32 Dual-Core IPCC Architecture

Zero-Copy Mailbox Cache Coherency Hardware Semaphores

Asymmetric multiprocessing (AMP) separating critical real-time attitude estimation (Cortex-M7) from communication protocol stacks and file systems (Cortex-M4).

  • Zero-Copy Pointer Exchange: Exchanging 32-bit descriptors via IPCC hardware registers pointing to shared SRAM3 without memory copying penalties.
  • Hardware Cache Coherency: Precise cache maintenance using SCB_CleanDCache_by_Addr() prior to transmission and SCB_InvalidateDCache_by_Addr() upon reception.
  • Atomic Resource Protection: Hardware Semaphores (HSEM) prevent concurrent access to shared SPI buses and flash.

Lock-Free Circular FIFO

SPSC Non-Blocking Power-of-2 Masking ARM __DMB() Barrier

High-frequency ring buffer piping UART/SPI telemetry and DMA ADC samples between interrupt handlers and FreeRTOS tasks without disabling interrupts.

  • Zero Modulo Division: Power-of-two capacity (SIZE = 16) wraps indices with bitwise AND (head & 0x0F), saving cycles on microcontrollers without hardware division.
  • Memory Barriers: ARM CMSIS __DMB() memory barrier guarantees bytes are committed to RAM before advancing indices.

Space Telemetry & RF Modems

GMSK BT=0.5 AX.25 UI Frame G3RUH 9600 CW Morse Beacon

Digital RF modem processing chains for CubeSat transceivers conforming to international amateur satellite standards.

  • GMSK Pulse Shaping: Gaussian pre-modulation filter ($BT = 0.5$) eliminates sideband splatter while maintaining a constant RF envelope.
  • AX.25 UI Frame: Layer-2 HDLC packet framing with 0x7E flags, bit stuffing, and 16-bit CRC-CCITT polynomials.
  • G3RUH Scrambler: Applied polynomial $1 + x^{12} + x^{17}$ LFSR whitening to guarantee clock recovery at ground stations (SatNOGS).

Fail-Safe LittleFS for CubeSats

Power-Loss Resilient Dynamic Wear Leveling Bounded RAM

Integrated LittleFS on external NOR Flash for mission flight logging, attitude calibration tables, and telemetry chunk storage.

  • Copy-on-Write Pairs: Prevents corruption during sudden power drops or battery low-voltage cuts.
  • Wear Leveling: Distributes erase cycles across blocks to extend flash endurance in space radiation environments.
